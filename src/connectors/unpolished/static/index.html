Unpolished — hosted MCP endpoint

This is the machine endpoint for the polish check from Unpolished: which habits in a piece of English writing models use far more often than people, with measured rates for both. It uses no model and stores nothing.

It measures habits, not authorship. It cannot tell whether a text was written by AI, and a match is not evidence that anyone used AI.

Try it:

curl -sS --http1.1 -X POST https://mcp.barbaros.dev/unpolished/mcp \
  -H 'Content-Type: application/json' -H 'Accept: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"list_tells","arguments":{"query":"delve"}}}'

Connectors and APIs (mcp.barbaros.dev)

Some of our projects expose a public API, callable by AI assistants such as Meta Muse (through the Muse Connector Platform) or by anyone directly, at mcp.barbaros.dev.

What we receive: only the arguments a request implies — for example, an app name, a question, or a search string. We do not require an account, a password, or an API key for these connectors.

What we don't collect: no personal data, no chat content, no Meta account identifiers. Nothing submitted through a connector is stored; requests are served from an in-memory snapshot of public data.

Logs: basic technical logs (IP address, path, status code, response time) are kept for up to 14 days for security and reliability, the same as the rest of this site. Request arguments and response bodies are not logged.

Sharing: we do not sell or share this data with third parties. It is not used for advertising or model training.

Source code for these connectors is public: github.com/barbarkaragul-oss/barbaros-mcp.

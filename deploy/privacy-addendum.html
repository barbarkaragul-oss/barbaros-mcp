Connectors and APIs (mcp.barbaros.dev)

Some of our projects expose a public API, callable by AI assistants such as Meta Muse (through the Muse Connector Platform) or by anyone directly, at mcp.barbaros.dev. None of them needs an account, a password, or an API key.

What we receive: only what a request contains. For PrivacyMatrix that is an app name, a question, or a search string. For the Unpolished polish check it is the text you ask it to check: your own writing, which may contain personal information.

What happens to it: each request is answered in memory and then discarded. Nothing you send through a connector is stored. A polish check sends back, to you only, counts and a few short excerpts of your own text so you can see which words were found.

Logs: since 24 October 2026 the connector server does not record IP addresses, browser details or anything you send. Its logs contain only the time, the path, the status code and the response time, and are used only to keep the service running. To apply the rate limit, the IP address is held in memory for up to a minute and is never written anywhere.

Sharing: we do not sell or share this data with third parties. It is not used for advertising or to train any model.

Source code for these connectors is public: github.com/barbarkaragul-oss/barbaros-mcp.
